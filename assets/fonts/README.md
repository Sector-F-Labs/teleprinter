# Fonts

MesloLGS NF (regular, bold, italic, bold italic): Meslo LG by André Berg, with the Nerd Font
glyphs patched in, as published in <https://github.com/romkatv/powerlevel10k-media>. The files
here are byte-identical to that release (renamed without spaces).

Licensed under the Apache License, Version 2.0: see [`LICENSE.txt`](LICENSE.txt). Meslo is
based on Apple's Menlo, which derives from Bitstream Vera Sans Mono (Copyright 2003 Bitstream,
Inc.) and DejaVu Sans Mono. Why these are bundled: [ADR-0002](../../docs/adr/0002-bundle-meslolgs-nf.md).

Noto Color Emoji (`NotoColorEmoji.ttf`, the CBDT build): from
<https://github.com/googlefonts/noto-emoji> at commit `e20cbc2b`, `2D/fonts/NotoColorEmoji.ttf`,
unmodified. Licensed under the SIL Open Font License 1.1: see
[`NotoColorEmoji-LICENSE.txt`](NotoColorEmoji-LICENSE.txt). Why it's bundled:
[ADR-0013](../../docs/adr/0013-colour-emoji-from-bundled-noto.md).
